# Weight function for weight_index

Weight function for weight_index

## Usage

``` r
weight_function(one_geo, x, geo, w_df, check_geos, mean_type)
```

## Arguments

- one_geo:

  A character of base geo

- x:

  A variable to weight

- geo:

  A vector of ids to weights

- w_df:

  A weigth data.frame

- check_geos:

  A locigal to check if all geos are in w_df

- mean_type:

  A meant type to calculate "geom" for geometric and "arit" for
  arithmetic
